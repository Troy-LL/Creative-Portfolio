# Archived: Desktop TL (Mac OS portfolio)

Snapshot of the interactive desktop-OS portfolio (Finder, dock, windows, mobile gate, Founders Cafe embed).

Parked here so the root site can be redesigned. Keep this folder runnable as selected past work.

Agent notes for this snapshot: `CLAUDE.md`, `GEMINI.md`, `mobile-context.md` in this folder. Greybox QA from the OS era stays at repo `docs/testing/` and `docs/superpowers/` (paths the archive e2e helpers still write).

## Run from repo root

```bash
npm run serve
```

Open http://localhost:4173/archive/desktop-os/

## Build Founders Cafe (from this folder)

```bash
node scripts/build-founders-cafe.cjs
```

(or `npm run build:founders-cafe` from repo root once scripts are wired)
